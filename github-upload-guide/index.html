📁 クライアントフォルダ移動手順書

sonosannのPC → クライアントのGitHubリポジトリ

作業の目的：sonosannのPC（またはNAS）にある [クライアント名] フォルダを、クライアントの GitHub リポジトリにアップロードして GitHub Pages で公開する。
1
クライアントがGitHubリポジトリを作成する

クライアントのGitHubアカウントで新しいリポジトリを作成します。

  • GitHubにログイン → 右上の ＋ → New repository
  • リポジトリ名を入力（例：my-portfolio）
  • 表示設定を 公共（Public） に設定
  • リポジトリを作成する ボタンを押す
▲ リポジトリ名・説明を入力
▲ 公共を選択して作成ボタンを押す
2
リポジトリにフォルダをアップロードする

作成直後のリポジトリ画面から、ファイルをアップロードします。

  • リポジトリ画面中央の 既存のファイルをアップロード（uploading an existing file）をクリック
  • sonosannから受け取った [クライアント名] フォルダをまるごとドラッグ＆ドロップ
  • 下部の Commit changes ボタンを押す
▲ 中央の青いリンクからアップロード画面へ
⚠️ $教材資料.code-workspace などのVSCodeファイルが混入していたら削除してください。
3
アップロード後のリポジトリを確認する

アップロード後、リポジトリにフォルダが入っているか確認します。

  • リポジトリトップに [クライアント名] フォルダが表示されていればOK
  • フォルダをクリックして index.html と image フォルダが入っているか確認
▲ フォルダ内にindex.htmlとimageフォルダがあればOK
4
GitHub Pages を有効にする

リポジトリの Settings から GitHub Pages を設定します。

  • 上部タブ Settings をクリック
  • 左メニューを下にスクロール → Pages をクリック
  • Source を Deploy from a branch に設定
  • Branch を main / / (root) に設定して Save
  • 数分待つと上部に公開URLが緑色で表示される
▲ 設定前：Branch が None の状態
▲ 設定後：URLが緑色で表示される
https://[クライアントのユーザー名].github.io/[リポジトリ名]/[クライアント名]/
✅ URLが表示されたらアクセスして動作確認してください。表示まで数分かかる場合があります。
5
Collaborator（共同編集者）にsonosannを追加する

クライアントがsonosannをCollaboratorとして招待することで、sonosannがVSCodeから直接プッシュできるようになります。

  • Settings → 左メニュー Collaborators をクリック
  • Add people ボタンを押す
  • kobayashi4556 を入力して検索・選択
  • Add collaborator を押して招待完了
  • sonosannのメールに招待が届くので Accept invitation をクリック
▲ Settings → Collaborators の画面
▲ Add people ボタンから招待する
✅ 招待後、sonosannがVSCodeからクライアントのリポジトリにプッシュできるようになります。
6
動作確認・URLをsonosannに報告する

公開されたURLをブラウザで開いてポートフォリオが正しく表示されるか確認します。

  • Settings → Pages に表示されているURLをコピー
  • ブラウザで開いてサイトが表示されることを確認
  • URLをLINEでsonosannに送って報告
✅ 404エラーが出る場合はGitHub Pagesの反映に時間がかかっています。5分待って再度アクセスしてください。

🎉 移動・公開完了！
